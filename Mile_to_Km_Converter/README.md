# Mile to Kilometer Converter
A simple desktop GUI application built in Python using the tkinter library that converts distances in miles to kilometers. This project was created as part of learning Python GUI development.

# Features
1. Clean and intuitive user interface.
2. Real-time conversion from miles to kilometers when the calculate button is pressed.
3. Handles user input via a standard entry box.

# Built With 
1. Python
2. Tkinter (Standard Python interface to the Tcl/Tk GUI toolkit)
