🐍 Python Turtle Snake Game

A classic, retro Snake game built in Python using the `turtle` module. Navigate the snake to eat food, grow longer, and achieve the highest score without running into walls or your own tail!

=> Game Controls

| Key           |      Action     |
| ----          |      ----       |
| Up Arrow      |      Move Up    |
| Down Arrow    |      Move Down  |
| Left Arrow    |      Move Left  |
| Right Arrow   |      Move Right |

- Score System: Tracks your current score and saves your highest score.
- Clean UI: Simple UI
