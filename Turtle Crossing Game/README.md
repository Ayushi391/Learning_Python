# 🐢 Turtle Crossing Game

A classic arcade-style game built using Python's native `turtle` graphics library.
the goal is simple: guide your turtle safely across a busy highway, dodge incoming traffic, level up, and achieve the highest score!

## Preview & Gameplay

- **Objective:** Reach the top of the screen without colliding with any moving cars.
- **Progression:** Each successful crossing resets the turtle's position, increases the game level, and speeds up the traffic.
- **Game Over:** If you collide with a car, the game ends immediately.

## Features

- 🎮 **Simple Controls:** Smooth, single-key responsive movement.
- 🚗 **Dynamic Traffic Generation:** Cars are randomly generated in vibrant colors and move horizontally across the screen.
- 📈 **Increasing Difficulty:** Car movement speeds up with every level completed.
- 🏆 **Scoreboard & UI:** Real-time level tracking and an animated "GAME OVER" display using custom font styles.
- 🐍 **Pure Python:** Built 100% using native standard libraries (`turtle`, `random`, `time`). No external dependencies required!
