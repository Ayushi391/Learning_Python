# 🔢 Number Guessing Game
A Python console game where the computer randomly chooses a number, and the player tries to guess it within a limited number of attempts. The game provides hints after each guess to help the player find the correct number.

## Features
- Randomly generates a secret number
- Two difficulty levels:
  - Easy (10 attempts)
  - Hard (5 attempts)
- Gives feedback after each guess:
  - 📈 Too high
  - 📉 Too low
- Tracks the remaining attempts
- Ends the game when the player guesses correctly or runs out of attempts
