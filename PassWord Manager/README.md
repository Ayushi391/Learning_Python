# 🔐 Python Password Manager GUI
A secure and user-friendly desktop password manager application built with Python and tkinter.

# Features
1. Graphical User Interface (GUI): Clean and intuitive interface built using Python's built-in tkinter module.
2. Random Password Generator: Automatically generate strong, randomized passwords containing letters, numbers, and symbols to ensure maximum security.
3. Data Saving & Storage: Securely save your website, username, and generated password into a local data file (data.json).
4. Search Functionality: Quickly look up previously saved credentials for any website using the search feature.
5. Clipboard Integration: Automatically copies generated or retrieved passwords to your clipboard for instant use.
6. Data Validation: Built-in alerts/warnings to prevent saving entries with empty fields.

# 🛠️ Built With
1. Python 3.x
2. Tkinter: Standard Python interface to the Tcl/Tk GUI toolkit.
3. JSON: For structured local data storage and retrieval.
4. Pyperclip: For cross-platform clipboard copy-pasting support.
