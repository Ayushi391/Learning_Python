#☕Coffee Machine
A python console application that simulates a coffee vending machine. Users can choose a drink, insert coins and receive their coffee if enough resources and money are available.

##Features 
1. choose between espresso, latte and cappuccino
2. checks if  enough ingredients are available
3. Accepts coin input (quarters, dimes, nickels, pennies)
4. Calculate total payment
5. Refund money if payment is insufficient
6. Returns change when extra money is inserted
7. Updates available resources after a successful purchase
8. Display a machine report
9. Turn off the machine using the 'off' command

## Commands
- `espresso`
- `latte`
- `cappuccino`
- `report`
- `off`
