# Turtle Pong Game 🏓
A classic two-player Pong arcade game built with Python's built-in turtle module.
Two players control paddles on opposite sides of the screen to bounce a ball back and forth, scoring points whenever the opponent fails to return the ball.

## Features
- Two-Player Local Multiplayer: Right paddle controlled using arrow keys; left paddle controlled using W and S keys.
- Dynamic Speed Increase: The ball accelerates every time it hits a paddle, increasing the challenge as the volley continues.
- Score Tracking: Real-time scoreboard displaying points for both players.
- Collision Detection: Accurate boundary detection for wall bounces and paddle hits.

## Built With
- Python 3
- Turtle Graphics Library (Standard Python Module)
