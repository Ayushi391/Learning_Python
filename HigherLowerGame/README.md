# 🎮 Higher Lower Game
A Python console game where the player guesses which person, brand, or organization has more social media followers. The game continues until the player makes an incorrect guess, while keeping track of the current score.

## Features
- Randomly selects two accounts for comparison
- Displays account information without revealing follower counts
- Accepts user guesses (`A` or `B`)
- Compares follower counts to determine the correct answer
- Keeps track of the player's score
- Ends the game when an incorrect guess is made
- Clears the screen between rounds for a better user experience

## How to Play
1. Two accounts are displayed.
2. Read the description of each account.
3. Enter:
   - `A` if you think Account A has more followers.
   - `B` if you think Account B has more followers.
4. Keep guessing correctly to increase your score.
5. The game ends when you make an incorrect guess.
